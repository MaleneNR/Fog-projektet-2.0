Din valgte carport

Tak for din bestilling! Nedenfor kan du se din valgte carport med materialeliste og vejledning.

Materialeliste (stk liste)

  • 8 x Stolper (300cm)
  • 20 x Spær (600cm)
  • 40 x Tagbrædder (400cm)
  • Skruer og beslag
  • Tagpap og søm

Vejledning / Konstruktion

Se tegningen for mål og placering af stolper og spær. Sørg for at alle stolper er fastgjort i frostfri dybde. Monter spærene som vist og afslut med tagbrædder og tagpap.
